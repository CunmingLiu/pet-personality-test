# 宠物动物系性格测试（微信小程序）

一个轻量、治愈风格的微信小程序：通过 20 道 MBTI 偏好相关题目，生成对应的动物人格结果，并支持生成分享海报。

## 功能特点

- 20 道题目测评（融合 MBTI 四维偏好与动物人格映射）
- 10 种动物人格结果展示（含标签与描述）
- 结果页可保存海报到相册、可分享给好友
- 使用云函数 + 云数据库存储题库、结果和答题记录

## 技术结构

- 小程序端：`miniprogram/`
- 云函数：`cloudfunctions/quickstartFunctions/`
- 数据集合：
  - `pet_questions`（题库）
  - `pet_results`（结果）
  - `pet_answer_records`（答题记录）

## 运行说明

1. 在微信开发者工具中导入项目并配置云开发环境。
2. 部署云函数 `quickstartFunctions`（云端安装依赖）。
3. 调用 `initMvpData` 初始化数据（可用 `force: true` 强制重置题库与结果）。
4. 编译运行小程序。
